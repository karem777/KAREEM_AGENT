# KAREEM_AGENT COMPLETE — Windows Operator

## الوظيفة الأساسية
مساعد Windows ينفّذ المهام باستخدام الأدوات المسجلة، يلاحظ نتائج التنفيذ ويحاول التعافي من الأخطاء ضمن حدّ خطوات، ويحتفظ بذاكرة خبرات محلية.

## التشغيل
من PowerShell داخل مجلد المشروع:

```powershell
cd C:\Users\Acer\KAREEM_AGENT
$env:KAREEM_FAST_MODE="0"
.\.venv\Scripts\python.exe app_complete.py
```

افتح `http://127.0.0.1:5000`.

## التنفيذ بالخلفية والتقارير
- اختر **Background** لإرسال المهمة إلى طابور يعمل في الخلفية؛ ستعرض الواجهة حالة المهمة وتحدّثها دوريًا.
- استعلم عن المهام عبر `GET /tasks` أو `GET /tasks/<task_id>`.
- بعد انتهاء كل مهمة خلفية، يحاول التطبيق كتابة تقرير TXT على Desktop. المهام المرئية تنشئ تقريرًا أيضًا عند رجوع التنفيذ.
- التقرير يلخّص المطلوب والنتيجة والإجراءات المسجلة والأخطاء. وهو لا يثبت صحة النتيجة بشكل مستقل؛ راجع الأدلة المهمة بنفسك.
- طابور الخلفية داخل العملية الحالية؛ إذا أُغلقت العملية أو أُعيد تشغيل التطبيق فلن تبقى حالة الطابور في الذاكرة، لكن التقارير المكتوبة ستظل على Desktop.
- وضع Background يعني تشغيل المهمة في خيط خلفي وعدم انتظارها في طلب الويب، وليس ضمانًا بأن كل تطبيق رسومي يعمل مخفيًا بالكامل.

## الأدوات
يتضمن المشروع أدوات Windows وPowerShell، والتحكم في التطبيقات، والملفات، وVS Code/تطوير المشاريع، والويب والذاكرة بحسب الأدوات التي يتم تحميلها بنجاح. قد تختلف القدرة الفعلية حسب صلاحيات Windows وتثبيت المتطلبات والأداة المستهدفة.
