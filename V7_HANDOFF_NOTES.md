# V7 Handoff Notes

1. Stop the currently running KAREEM_AGENT before updating.
2. Extract this folder anywhere.
3. Run `INSTALL_V7.bat` for a first install or migration.
4. Run `SELF_TEST_V7.bat`.
5. Then start KAREEM_AGENT normally.

The safest first live test is a tiny external-browser task such as:
`افتح جوجل وابحث عن OpenAI`

Do not use the agent's own `http://127.0.0.1:5000` UI as the task target.
